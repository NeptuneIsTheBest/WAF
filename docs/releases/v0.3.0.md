# WAF v0.3.0

全局安全规则正式版，提供内置中文管理后台的 Linux amd64 / arm64 安装包。

## 升级前必读

**本版本包含不兼容的配置结构变更，不支持直接沿用 v0.2.0 及更早版本的站点级安全配置。**

- 自定义规则、速率限制和托管规则统一迁至 `Bundle.security`。旧字段 `sites[].rules`、`sites[].rate_limits` 和 `sites[].managed` 会被明确拒绝。
- 旧配置、历史配置版本和旧备份不会自动转换为新结构；新版不会自动清空旧数据库。
- 升级前保留旧二进制、完整旧数据目录、主密钥及备份。使用新的数据目录初始化 v0.3.0，再重新录入站点和全局安全规则，完成业务验证后切换流量。
- 需要回退时，恢复旧二进制及与其兼容的完整旧数据。新版结构内的草稿、发布、配置回滚和备份恢复继续受支持。

安装器只用于首次安装，遇到已有配置或数据会退出。详细操作见 [v0.3.0 运维文档](https://github.com/NeptuneIsTheBest/WAF/blob/v0.3.0/docs/OPERATIONS.md)。

## 主要变化

- 全局管理自定义规则和速率限制，可选择所有网站或指定多个网站；所有网站范围自动覆盖以后新增的网站，也可在添加网站前配置规则。
- 网站范围与 CEL 表达式同时匹配才生效，表达式新增 `site.id`。速率限制共享规则配置，各网站独立计数，同一网站的多个域名共享额度。
- 托管规则支持全局默认防护和按优先级匹配的条件覆盖，每个请求只执行一套托管策略；例外可限定网站、路径和参数。
- 安全事件新增 `managed_policy_id`，支持定位产生事件的托管策略并添加范围明确的例外。
- 管理界面、OpenAPI、运维文档和测试同步采用全局安全配置。管理 API 路径继续使用 `/api/v1`，表达式验证请求新增 `scope`。

## 下载与安装

支持 Ubuntu 22.04+ / Debian 12+，使用 systemd 管理服务。选择对应架构的安装包：

- `waf_0.3.0_linux_amd64.tar.gz`
- `waf_0.3.0_linux_arm64.tar.gz`

安装包与独立安装脚本 `install.sh` 的 SHA-256 校验值见 `SHA256SUMS`。

首次安装时，下载本发布的 `install.sh` 后执行：

```bash
sudo bash install.sh --version v0.3.0
```

按提示填写域名、邮箱、密码和 Cloudflare Token，并保存初始化时显示的 TOTP 密钥及恢复码。
